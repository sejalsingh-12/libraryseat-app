# 📚 Library Seat Management System

A responsive web application designed to help students quickly find and reserve available seats in a library without wasting time searching manually.

## 🚀 Features

- 🔍 View available and occupied seats
- 🏢 Navigate between different library levels
- 💺 Select and reserve seats
- 📊 View real-time seat status
- 🔎 Search and filter available seats
- 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- Vite
- HTML5
- CSS3

## 🎯 Problem Statement

Students often spend unnecessary time searching for vacant seats in a library, especially during busy hours. This project provides a centralized interface where students can view seat availability and select a suitable seat before moving around the library.

## 💡 Solution

The system displays library seats with different availability statuses, allowing students to easily identify vacant seats and reserve them through an interactive interface.
